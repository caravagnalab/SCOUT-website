SCOUT

We developed SCOUT, a synthetic whole-genome sequencing (WGS) cohort comprising seven tumour models with matched tumour–normal pairs. A detailed description of the cohort is available here. We simulated Illumina sequencing under nine combinations of tumour purity and sequencing depth using ProCESS. The resulting reads were preprocessed and analysed for somatic variants using nf-core/sarek. Subsequently, subclonal reconstruction and mutational signature deconvolution were performed using nf-core/tumourevo.
